BaraBeat Studio

User guide for the score editor, instant playback, practice mode, audio player and Arrangement.

This guide describes the development status of August 2026.

1. Quick start

BaraBeat Studio is an editor and player for Djembe and Dunun notation. You can notate Patterns such as Call, Intro, Accompaniment Pattern, Solo or Échauffement and listen to them immediately.

BaraBeat in under 3 minutes

The video shows the essential steps from the first entry in the score to playing and saving a rhythm. You can then follow the individual quick-start steps at your own pace.

Fast workflow

  1. Use File to open an existing score, or use Score to create a new one.
  2. Enter the rhythm name at the top of the score.
  3. Label the part with the instrument and function choosers, for example Djembe 1 and Accompaniment Pattern.
  4. Place notes and, if required, control marks from the palette on the grid.
  5. Activate the selection box in front of the Pattern you want to hear.
  6. Set the BPM and start instant playback with the Play button.
  7. Use File → Save to store your work; use Save as for a new name or a copy.

For systematic training, switch to practice mode; build longer sequences in the Arrangement. On smartphones, portrait orientation is mainly for reading and playback, while landscape orientation is for editing.

2. Interface

The application consists of the score, a movable palette, the main menu and optional work views for practice mode and Arrangement.

Main menu

MenuPurpose
FileOpen and save scores, manage them locally or on the server, export them and select the language. On smartphones, the user guide is also available here.
ScoreCreate a binary, ternary or 9/8 score and add or delete pages.
InsertInsert additional elements or templates.
ToolsOn the desktop, open practice mode, Arrangement, the user guide and template selection.

Language

Under File → Language, you can select Deutsch, English, Français, Español or Português. BaraBeat Studio remembers the selection and uses it again the next time you open the application. Language selection changes visible controls and messages only; musical data, free text and saved scores are neither translated nor modified.

Sign-in

If access protection is enabled, BaraBeat Studio first asks for a password. Sign-in remains valid in that browser or Home Screen app until you choose File → Sign out or delete the browser data. Sign out after working on a shared device.

Administration: temporary access

After signing in normally, you can use File → Open access for 5 min to suspend password protection temporarily for all visitors. This also applies to automated browsers, API requests and testing tools without a sign-in or cookie. A confirmation prevents accidental activation. The button shows the remaining time and can close the access window early; protection is restored automatically after five minutes.

During this window, BaraBeat Studio marks responses with noindex and no-store. Automated tools may access the application, but search engines should neither index nor cache the temporarily open application.

Templates

Under Tools → Template, you can switch between visual presets including Clear, Playful and Earthy. Templates change the visual mood of the interface, not the musical data.

3. Opening and saving files

Scores are stored as .bbs files. Older .txt scores can still be opened.

Open

  • Local shows scores stored in this browser or Home Screen app. They can be organised in folders and subfolders.
  • Server shows scores from the Noten/ folder. The server list is refreshed whenever the dialog opens.
  • When loading from the server, BaraBeat Studio remembers the download time and server-file version. If it subsequently changes on the server, Server changed since then appears. Local editing is shown separately as Locally changed with its time.
  • When required, the notice above the file list offers Load server version.
  • On smartphones, the file view is simplified so that opening and deleting local files remain easy to reach.

Save

  • Save overwrites the currently open score.
  • Save as is intended for new names or copies.
  • Save as is also available on iPhone, allowing scores created or changed in the mobile editor to be stored locally or on the server.
  • You can create and rename folders in the local library. A folder can only be deleted when it contains no scores or subfolders.
  • A successful save produces a brief status message. Error messages remain visible.

Publish on the server

Saving to the server publishes the score and also keeps it as a local file. BaraBeat Studio stores a publish token in that local copy. The token proves later that you are allowed to update or withdraw the publication.

  • Saving the same published file to the server again updates its publication.
  • Using a new name creates a new publication.
  • Delete publication removes the server version; the local file remains.
  • Without the publish token, the server file can still be read but cannot be updated or deleted as your publication. Use the browser or Home Screen app from which it was published.

The status column distinguishes local files, publications and locally changed versions. For server files, BaraBeat Studio also shows whether the publication has changed since it was last loaded.

SVG, PDF and printing

Under File → Export, enter a file name and select the format:

  • SVG is a scalable vector file suitable for further editing or high-quality display.
  • PDF is suitable for sharing and printing with a consistent page layout.

To print, open the exported PDF and use the browser or operating system print command. BaraBeat Studio does not have a separate print dialog.

Note: The score stores not only the drawn notes but also practice settings, saved practice scenarios, Pattern selections, the Arrangement timeline, volumes, Swing, Feel and other metadata.

4. Editing the score

The score is the basis of all other functions. Patterns are created from passages labelled with an instrument chooser and a function chooser.

Score types

TypeGridTypical use
BinaryFour subdivisions per pulseMany straight Djembe and Dunun rhythms
TernaryThree subdivisions per pulseTriplet-based rhythms
9/8Three groups of threeSpecial 9/8 rhythms such as Koreduga

Multi-page scores

A score can have several pages. Each page displays ten lines. If more lines are needed, use Add page. The legend is placed on the last page, and page numbers such as 1/2 and 2/2 appear at the lower right.

Palette

The palette contains note symbols, choosers and control marks. On the desktop it remains visible while scrolling and can be moved when required. In the mobile landscape editor it appears as a horizontally scrollable toolbar at the bottom of the display.

Setting the instrument and function

The instrument chooser sets the voice, for example Djembe, Kenkeni, Sangban, Dununba or Ballet Dununs. The function chooser describes the Pattern’s role, such as Call, Intro, Accompaniment Pattern, Solo, Échauffement or Outro. For Accompaniment Pattern and Solo, you can enter a custom label such as Accompaniment Pattern 2 or Solo 1. This custom label reappears in the input field when you edit it later.

In BaraBeat Studio, Ballet Dununs denotes the combined part or jointly played set of Kenkeni, Sangban and Dununba.

Rhythm name

The rhythm name appears at the top of the score and can be edited directly. On startup, the last loaded title is restored if the browser still has that information.

Instant playback from the score

A BPM field and Play button appear next to the rhythm name. Small selection boxes before the Patterns mark what should be played directly from the score. They become active as soon as a measure is recognised as playable through an instrument, Pattern name or notes; saving and reloading first is unnecessary. On iPhone, the header with rhythm name and Play button stays visible while scrolling.

  • One selected Pattern loops until you press Stop.
  • Patterns on different instruments play in parallel.
  • Patterns on the same instrument play in sequence.
  • A selected Accompaniment continues while an additional Solo plays in parallel. An Out in the Accompaniment is ignored to keep the loop seamless.
  • Notes currently sounding are briefly highlighted in the score.

Moving a complete Pattern

A complete Pattern, including notes, choosers and additional marks, can be moved up or down. Use the arrows at the beginning of the Pattern. This is available in both the desktop editor and the mobile landscape editor.

5. Symbols and special marks

The principal symbols correspond to the legend in the score.

SymbolMeaning
ToneOpen Djembe Tone.
BassDjembe Bass stroke or Dununba stroke, depending on the instrument part.
Slap / bellSlap on Djembe; bell on Kenkeni, Sangban, Dununba or Ballet Dununs.
FlamTwo closely spaced strokes. Flams overlap in the moving-note display.
Muffled Tone / muffled SlapMuffled strokes, marked by an underline in the score.
InPickup or entry point. The note below the In may occur before the Pattern proper.
OutExit point. The note above the Out is still played, after which the voice ends.
RepeatInternal repeat within the Pattern. The number by the mark gives the repeat count.
ShortBarShortens a measure without making it visually narrower. Omitted units are shown with dashed lines.
Triplet / quadrupletAdditional symbols for even subdivisions. Binary scores show a T for triplets; ternary and 9/8 scores show a Q for quadruplets.
ShortBar: In binary rhythms, ShortBar omits the final four units; in ternary and 9/8 rhythms, it omits the final three. The visual structure remains stable while audio and moving notes observe the shortened length.
Out in an Accompaniment Pattern: In an Arrangement, an Out can mark a deliberate exit in an Accompaniment. In practice mode, an Out in an Accompaniment Pattern is normally ignored so that loops continue. It may apply when the Accompaniment is explicitly set to stop before Call/Intro, or when an Accompaniment Pattern used as a practice part should exit on its final pass before the next Call/Intro.

The triplet/quadruplet symbol changes with the score type in the palette and legend. Its compact form uses three dots and a letter: T for triplet or Q for quadruplet. After clicking the symbol, select the stroke for each individual note. The completed compound symbol is created beside the palette and can then be dragged onto the score.

6. Selection, copying and undo

Elements can be moved individually or marked together with a selection rectangle. After moving, the selection remains active until you click outside it.

Keyboard

KeyFunction
Alt while draggingClone an element.
Cmd + ZUndo.
Cmd + Shift + ZRedo.
Cmd + CCopy selection.
Cmd + XCut selection.
Cmd + VPaste. Pasted elements remain selected and can be moved immediately.

Delete

On the desktop, use Cmd + X to cut and remove a selection. In the mobile landscape editor, the delete tool removes either the tapped element or the whole current selection. Choosers can also be removed with their own delete control.

Copying between tabs

Selected score elements can be copied through the clipboard between two browser tabs or windows. If the browser blocks access to the system clipboard, BaraBeat Studio also uses a local clipboard in the open tab.

Grid behaviour while moving

While dragging, an element follows the pointer smoothly. When released, it snaps to the nearest sensible position. This applies to notes, repeat marks, In/Out, ShortBar and choosers.

Selection on iPhone

In the mobile landscape editor, activate the selection tool in the lower palette and draw a rectangle around the required elements. You can move the selection together, copy it with the duplicate tool or remove it with the delete tool. Normal iOS text selection is suppressed in the score area so that its gestures do not conflict with the editor.

7. Audio player

The audio player plays a practice session or Arrangement. In its standalone view, it can also play selected voices from a score.

Controls

  • BPM controls the tempo in beats per minute.
  • Play starts or stops playback.
  • Voice selects individual instruments or groups in the standalone player.
  • Export WAV renders the current practice session or Arrangement as a WAV file when this button is available in the current configuration. It may be hidden on smartphones because mobile browsers handle downloads differently.

Instruments and volumes

In practice mode and Arrangement, Volume opens the instrument mixer. Djembe voices, Kenkeni, Sangban, Dununba, Ballet Dununs and Shekere can be adjusted or muted separately. For individual instruments, the relative levels of strokes such as Bass, Tone, Slap or Mute can also be set.

Bluetooth latency

Practice mode includes Bluetooth latency ms. It offsets the display relative to the audio so that the red line and audible stroke coincide with Bluetooth headphones. On iPhone, the setting is available under Latency and is saved on the device.

Moving notes

Below the player, the notes being played move from right to left beneath a fixed red line. A stroke sounds when its symbol reaches the line. Bar lines, Pattern shading, instrument name and Pattern name aid orientation.

Depending on the mode, the right side of the header shows the number of remaining repeats or the remaining practice time. With tempo progression active, it first shows the remaining progression repeats.

8. Practice mode

Practice mode is designed for repeated training of individual Patterns. It reads Patterns from the score and builds a practice loop.

Pattern selection

Pattern selection can be opened or closed. It has three main areas:

  • Settings for Accompaniment start, repeats, timer, Swing, Feel, Mute and latency.
  • Select Accompaniment for Patterns that run in parallel as the foundation rhythm.
  • Select practice parts for Calls, Intros, Solos, Échauffements, rests and Accompaniment Patterns to be practised.

On the desktop, Settings initially opens collapsed; Select Accompaniment and Select practice parts are expanded. On smartphones all three initially remain collapsed so that the player and moving notes stay prominent.

Practice scenarios

Several practice scenarios can be saved for one score. A scenario contains the current settings, selected Accompaniments and practice parts, order, repeats, timer, tempo progression, volumes and other values. Scenarios are saved with the score.

Select the active scenario beside Practice mode at the top or in Pattern selection. The list is alphabetical. Current settings means that no saved scenario is currently active.

New saves the current configuration under a new name. Save updates the selected scenario and Delete removes it. These actions also update the locally saved score.

Accompaniment starts

The Accompaniment can start immediately, after Call, after Intro or after Call and Intro. If Call or Intro are already selected as practice parts, they are not added twice. Rests and ShortBars are observed so that the Accompaniments restart together afterwards.

Accompaniment stops at Call/Intro

This option is intended for rhythms in which the Accompaniment pauses for a Call or Intro and then resumes.

Practice parts and order

You can select several practice parts and drag them into the required order. The repeat count in an individual block determines how often that Pattern is played within the practice sequence. Optionally, the Accompaniment can play alone between practice parts.

Repeats and timer

  • Repeats sets how often the practice loop is played.
  • Timer can instead set a practice duration in minutes.
  • When the timer is active, the current practice loop finishes rather than stopping in the middle of a Pattern.

Tempo progression

Tempo progression provides a start tempo and a target tempo. You can also specify after how many repeats the tempo rises and by how much. The progression is completed first; normal repeats or timer duration continue afterwards.

The audio player displays the current BPM while the progression is running.

Sticking and H2H rest = Mute

Sticking can be selected for each Djembe Pattern, for example Auto, H2H or other modes. With H2H rest = Mute, empty notes become quiet Mute strokes. Their level can be set separately for each instrument.

Volume in practice mode

Clicking an instrument name beside the moving notes opens its volume control. A further overlay for individual stroke types can be opened there, allowing Bass, Tone, Slap or Mute to be adjusted relative to one another.

Shekere beat

Before a practice session starts, Shekere counts in four beats. Shekere beat can also accent every beat during playback. This is available in practice mode and Arrangement; Shekere has its own volume setting.

9. Arrangement

The Arrangement is the timeline for complete sequences. Patterns from the Pattern library are dragged into sections and played there in sequence or in parallel.

Pattern library

All Patterns found in the score appear on the left. Drag a Pattern into the timeline or use the plus button to append it.

Sections

A section contains one or more Patterns. Patterns in the same row play in parallel. The repeat count on the left determines how often the section runs. Shorter Accompaniments can continue cycling when a longer Accompaniment determines the number of passes.

Adding in parallel

When you drag a Pattern into an existing section, a parallel drop zone appears only when the Pattern can be used there musically. An instrument cannot play two different main Patterns of the same type at once, except when a Solo deliberately replaces an Accompaniment.

Solo cells

Accompaniment sections with several repeats show a Solo grid. Each cell represents one pass. A Solo dropped into a cell plays in parallel with the Accompaniment only during that pass.

  • If the Solo is shorter than the Accompaniment pass, the remainder is silent.
  • If the Solo is longer, the section continues for the required duration.
  • If the same instrument plays Accompaniment and Solo, the Accompaniment pauses during the Solo and resumes afterwards.
  • In and Out are also observed for Solos.

Moving sections

Sections can be moved up or down in the timeline, allowing an Arrangement to be reorganised without rebuilding its Patterns.

BPM in the Arrangement

Each section can have its own BPM. A tempo change glides to the new BPM over about two measures and remains in effect for subsequent sections until another change is set.

Shekere and volumes

Shekere beat is also available in the Arrangement. Swing profile, Feel and volumes open from the controls above the timeline. Instrument volumes are shared by practice mode and Arrangement and saved with the score.

Undo and redo

Timeline changes are recorded in the same history as editor and practice-setting changes. On the desktop, Cmd + Z undoes the last step; Cmd + Shift + Z redoes it.

10. Sound, Swing and Feel

BaraBeat Studio provides several levels of sound adjustment.

Instrument volume

The overall level of individual instruments, including Shekere, can be set from the moving notes in practice mode. These values are saved with the score.

Stroke volume per instrument

The different strokes of an instrument can also be balanced relative to one another, for example Bass, Tone, Slap, Mute or muffled strokes. This is useful when samples were recorded at different levels.

Swing

Swing profile opens an overlay in which subdivision displacement is displayed and adjusted. Note symbols can also be dragged horizontally; the maximum offset is limited to 50 % of the distance to the neighbouring grid position. The profile applies to all Patterns in the score; there are no separate Swing values per Pattern.

Feel

The Feel overlay moves individual instruments forward or backward by milliseconds. Instrument names are written in full so that the adjusted part is unambiguous.

In practice: Swing changes the internal distribution within a pulse. Feel shifts complete instruments slightly relative to one another. Together they can make a rhythm more lively, but should be used carefully.

11. Using BaraBeat on smartphones

On smartphones, BaraBeat Studio can open, display, play instantly, practise and edit scores. Display and editing functions switch automatically with device orientation. An existing Arrangement timeline can be played on mobile but cannot yet be edited there.

Mobile operation

The menu bar shows only commands relevant to the current mode. Under File you will find Open, Save, Save as, the user guide and Sign out. The persistent Back to the score button returns from the mobile guide to the application. In practice mode, Pattern selection and Latency are also available. If the score contains an Arrangement, Play Arrangement appears outside practice mode and opens the player in an overlay.

Portrait and landscape

  • Portrait: compact reading view with one measure per row, instant playback, practice mode and playback of existing Arrangements.
  • Landscape: mobile score editor with a larger measure grid, Score menu and horizontal palette.

Mobile score view

Multi-page scores are displayed page by page, rather than shrinking the entire stack to one screen height. Each measure has its own row. Multi-measure Patterns are grouped compactly in portrait view; instrument and Pattern name appear only at the start.

In the moving notes, instrument and Pattern name share one compact line. The red play line is drawn only across the actual note rows so that longer names remain readable.

Editing notes in landscape

  1. Turn the iPhone to landscape. The landscape editor appears automatically.
  2. Select a note or control mark in the lower palette, then tap the required grid position.
  3. Existing notes and marks can be touched directly, moved and snapped to the grid on release.
  4. Draw a rectangle with the selection tool. The selection can then be moved, duplicated or deleted together.
  5. Use Insert instrument and function to add both choosers to an empty measure. Existing choosers can be changed, moved or deleted.
  6. The arrows in the chooser row move a complete Pattern with all associated elements up or down.
  7. Edit the rhythm name directly at the top. The text tool inserts comments in a measure; existing text can be changed in the displayed input field.
  8. Use File → Save or Save as to store the changes.
Touch operation: The palette remains at the bottom and scrolls horizontally. Double-tapping a repeat mark opens its settings as on the desktop. The iOS keyboard may appear for inputs; closing it keeps the score scale unchanged.

Instant playback on iPhone

Pattern selection boxes, BPM and Play are also available on mobile. Several instruments can play in parallel; Patterns on the same instrument are handled in sequence. Sounding notes are briefly highlighted. The header remains visible while scrolling so playback can always be stopped.

Offline use

  1. Open BaraBeat Studio fully once on iPhone over an HTTPS connection.
  2. Wait for Offline ready. The interface, audio player and sounds are then prepared on the device.
  3. Load required scores from the server once in advance. They will then be in the local library.
  4. Optionally add it as a web app in Safari with Share > Add to Home Screen.

Without a connection, local scores can be opened, displayed, edited and played, and saved locally. The server list, loading again from the server and saving to the server still require an internet connection.

Background and Lock Screen

On supported iPhones and browsers, BaraBeat Studio uses Media Session and a playback audio session. Audio can therefore continue with the screen locked. The Lock Screen shows the title, BaraBeat logo and playback controls; Play, Pause and Stop can be used there. The controls available depend on iOS, browser and output device.

Back up local data before deleting: Safari and an added Home Screen app may use separate local storage areas. Deleting the Home Screen item can remove its local scores, practice scenarios, settings and offline data. Adding it again does not restore them automatically. Save important scores to the server first; embedded practice scenarios are stored with the file. Server files are unaffected.

Performance and memory

iOS Safari is sensitive to audio and large numbers of DOM elements. The player therefore conserves memory: repeats are not unnecessarily prerendered in full, moving notes are built in a limited window and samples are not held more than necessary.

12. Typical workflows

Notating a new Pattern

  1. Create a new binary, ternary or 9/8 score and enter the rhythm name.
  2. Set the instrument chooser, for example Djembe 1.
  3. Set the function chooser, for example Accompaniment Pattern, Call or Solo 1.
  4. Drag notes from the palette onto the staff.
  5. Add In, Out, Repeat, ShortBar or the triplet/quadruplet symbol if required.
  6. Save.

Saving and reopening

  1. Use File → Save to update the current local file or Save as to create a new version.
  2. Under File → Open, select Local.
  3. Open the appropriate folder if required, select the score and load it.
  4. To open a server version, switch to Server. Loading creates a local version.

Exporting SVG or PDF

  1. Open File → Export.
  2. Choose a file name and SVG or PDF.
  3. Start the export. To print, open the PDF in the browser or operating system.

Editing on iPhone

  1. Open the score and turn the iPhone to landscape.
  2. For a new measure, first tap the chooser tool in the lower palette and then Insert instrument and function here.
  3. Select the instrument and Pattern type.
  4. Select a note symbol in the palette and tap its required position in the measure.
  5. Move elements directly or mark several with the selection tool.
  6. Use File → Save or Save as.

Checking a Pattern instantly

  1. Activate the selection box before the Pattern.
  2. Select further Patterns if required.
  3. Set the BPM at the top of the score.
  4. Press Play. The selection loops and sounding notes are highlighted briefly.
  5. Press the button again to stop.

Practising a Pattern

  1. Open practice mode.
  2. Open Pattern selection.
  3. Select an Accompaniment.
  4. Select and order one or more practice parts.
  5. Set repeats or timer.
  6. Optionally save a practice scenario for later use.
  7. Press Play.

Building an Arrangement

  1. Open Arrangement.
  2. Drag Patterns from the Pattern library into the timeline.
  3. Drag Patterns into the same section when they should play in parallel.
  4. Set repeats.
  5. Place Solos in Solo cells.
  6. Check BPM, Swing, Feel and volumes.
  7. Play or export as WAV.

13. Troubleshooting

A Pattern is not recognised

  • Check that the instrument and function choosers are positioned correctly above the Pattern.
  • Check that notes sit on the grid.
  • For 9/8 rhythms, make sure In, Out and ShortBar use suitable grid positions.

Playback sounds displaced

  • Check Bluetooth latency.
  • Check Feel values.
  • At Pattern transitions, check In/Out and ShortBar.

The moving notes show gaps

  • Check whether very long repeats or many simultaneous Patterns are active.
  • On iPhone/Safari, test with realistic repeat values.
  • For newly constructed files, save and reopen so metadata is updated cleanly.
  • At transitions involving Call, Intro, ShortBar or Accompaniment Out, check that the intended practice case has actually been saved as a scenario.

The timeline shows “mixed”

This can appear when parallel Patterns in a row have different repeat structures. One-pass Accompaniment groups carried through a longer section should no longer be shown as “mixed”.

A sample is missing

If a sample is missing or cannot be loaded, the player should display an error. Check its spelling in the sound folder and whether the file exists on the server.

The mobile editor does not appear

The iPhone editor is enabled only in landscape. Make sure orientation lock is off and rotate the iPhone again. Portrait intentionally retains the compact reading and playback view.

There is no sound on iPhone

First check volume, audio output and Bluetooth. On supported devices, BaraBeat Studio uses a playback audio session so audio can work in silent mode. After an iOS or browser change, another tap on Play may still be required to authorise audio output.

Offline data is missing after reinstallation

If the Home Screen app was removed and added again, iOS may have created a new local storage area. Reload the required scores from the server. Purely local files can only be restored if they were backed up beforehand.

A server file does not show the expected version

Reopen the file dialog to refresh the server list. Check the status and modification columns for local edits or a changed server version. Load server version replaces the local version after confirmation.

A publication cannot be updated or deleted

These actions require the publish token in the local file. Open it in the browser or Home Screen app from which it was published. A file merely loaded from the server can be read but does not automatically have management permission.

The selected language does not change the score

This is intentional: language selection translates controls and messages only. Rhythm names, free text, Pattern labels and musical data remain unchanged.

The SVG or PDF cannot be found

The export is sent to the browser as a download. Check the download folder or, on iPhone, Files and Safari’s download display. Browser pop-up or download restrictions may require another confirmation.
